1.로또 생성기 웹문서 만들기
2.목적:버튼누르면 1~45중 중복 없는 6개 번호를 뽑아 화면에 보여주는 웹페이지
3.기능:번호뽑기버튼,공6개가 화면에 표기,오름차순 정렬,초기화버튼,생성횟수표시
4.입력:사용자의 버튼 클릭으로 실행
5.출력:번호 찍힌 공모양으로 출력해줘/ 생성횟수
6.제약:html / css / javascript 만 사용해서 만들어줘, css파일과 javascript파일은 각폴더를 만들고 그안에 저장해줘,외부 라이브러리 금지, 메인파일이름은 Lotto.html
7. 함수와변수에 주석을 상세히 작성해줘(한국어로)
8.확인기준 : 번호6개가 항상 나오는지 확인,1~45범위인가 확인, 초기화 후
